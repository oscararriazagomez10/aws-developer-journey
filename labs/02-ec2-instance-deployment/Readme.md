# EC2 Web Server Deployment Lab

## Overview

This lab demonstrates how to deploy a web server using Amazon EC2.

## Objectives

- Create an EC2 instance.
- Configure network access.
- Connect using SSH.
- Deploy Apache web server.

## AWS Services

- Amazon EC2
- Security Groups
- EBS
- SSH
