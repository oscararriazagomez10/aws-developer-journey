# Lab 01 - IAM User Management

## Overview

This hands-on lab focuses on AWS Identity and Access Management (IAM), one of the core security services in AWS.

The purpose of this lab is to gain practical experience creating and managing IAM users, groups, policies and configuring AWS CLI while following AWS security best practices.

---

## Objectives

By completing this lab, I was able to:

- Create IAM users.
- Create IAM groups
- Assign permissions using policies.
- Configure AWS CLI.
- Apply the Principle of Least Privilege.
- Understand secure identity management.

---

## Lab Workflow

1. Created an IAM user.
2. Created an IAM group.
3. Attached AWS managed policies.
4. Configured AWS CLI.
5. Verified credentials.
6. Tested IAM permissions.

## Key Takeaways 

- IAM improves AWS account security.
- Least Privilege reduces security risks.
- AWS CLI enables automation.
- IAM Groups simplify permission management.
- Roles should be preferred over permanent credentials whenever possible.
