# ☁️ Amazon EC2

## Overview

Amazon Elastic Compute Cloud (Amazon EC2) is a core AWS service that provides scalable virtual servers in the cloud.

This module documents both the theoretical concepts and practical knowledge acquired while studying Amazon EC2 as part of the **AWS Certified Developer – Associate (DVA-C02)** certification.

The goal is to understand how to deploy, secure and manage cloud-based virtual machines following AWS best practices.

---

## Learning Objectives

By completing this module, I aim to:

- Understand the purpose of Amazon EC2.
- Launch and manage EC2 instances.
- Select the appropriate Amazon Machine Image (AMI).
- Understand EC2 instance types and pricing models.
- Configure networking and Security Groups.
- Connect securely to Linux instances using SSH.
- Attach IAM Roles to EC2 instances.
- Apply AWS security best practices.
- Manage the EC2 instance lifecycle.
