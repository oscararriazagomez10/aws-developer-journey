# IAM and AWS CLI

## Overview

This module introduces AWS Identity and Access Management (IAM) and the AWS Command Line Interface (AWS CLI).

IAM is the services responsible for authentication and authorization in AWS, allowing secure management of users,groups,roles and permissions.

AWS CLI provides a command-Line interface to interact with AWS services,making it easier to automate task and manage cloud resources efficiently.

---

## Learning Objectives

After completing this module, I am able to:

- Understand the purpose of AWS IAM.
- Create and manage IAM users and groups.
- Apply IAM policies and permissions.
- Understand the difference between users, groups and roles.
- Configure AWS CLI.
- Execute basic AWS CLI commands.
- Apply AWS security best practices.
