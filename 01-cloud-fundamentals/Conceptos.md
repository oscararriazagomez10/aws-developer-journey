## Conceptos para Ampliar conocimientos

### Cloud Computing

#### ¿Qué es?
Es el uso de recursos informáticos  como servidores, almacenamiento, base de datos y software atraves de internet 


#### ¿Para que sirve?
Su plincipal uso es para almacenar datos, ejecutar programas y procesar información atraves de internet.

#### Ventajas
Ahorro economico:
Acceso Remot
Actualizaciones automaticas
Copias de seguridad
