# Interview Notes - AWS Fundamentals

## What is AWS?

AWS (Amazon Web Services) is a cloud platform that provides infrastructure and software services on demand.

---

## What is a Region?

A Region is a geographic area where AWS has multiple data centers.

## What is an Availability Zone?

An Availability Zone is an isolated data center inside an AWS Region.

---

## Difference between Scalability and Elasticity

Scalability is the ability to increase resources to handle more workload.

Elasticity is the ability to automatically adjust resources depending on demand.

---

## Shared Responsibility Model

AWS manages the security of the cloud.

The customer manages security inside the cloud, including data, permissions and configurations.
